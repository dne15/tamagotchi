### Tamagotchi
A browser-based virtual pet game built with HTML, CSS, and JavaScript.

**What I built:**
- A pixel art giraffe pet with happy, sad and dead states
- Real-time stat tracking (hunger, happines and energy) that change over time
- Interactive buttons to feed, play with and put the pet to sleep
- A welcome screen with name input and a game over/try again flow

**What I learned:**
- Managing application state with JavaScript objects and boolean flags
- Manipulating the DOM to update the UI in response to state changes
- Using `setInterval` to make things happen over time
- Writing reusable utility functions like `clamp()`
- Structuring a page into screens using flexbox and show/hide logic
